# Weather Dashboard

A responsive weather dashboard built using:

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- OpenWeatherMap REST API

## Features

- Search weather by city
- Real-time weather data
- Temperature
- Humidity
- Wind Speed
- Pressure
- Visibility
- Weather Icons
- Error Handling
- Recent Searches using Local Storage
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript
- REST API
